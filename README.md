## Установка backend части
У вас должен быть установлен [docker](https://www.docker.com/)

1. Клонирование репозитория
- по HTTPS
   
```git clone https://github.com/OkulusDev/Oxygen.git```

- по SSH

```git clone git@github.com:1e0nid/PolyPaste.git```

2. Переход в директорию PolyPaste

```cd PolyPaste```

3. Установка и запуск doker-compoese.yml

```docker compose up -d```

4. Запуск приложения
   
```mvn spring-boot:run```
